# 原文存档（仅研究核对用，**不入库**）

本目录存放可公开获取的原文副本，用于核对引用内容。
**本目录下的 PDF 一律不进开源仓库的版本控制**——出版方文件再分发有版权顾虑。

因此仓库里**只保留这份说明**；`*.pdf` 已由根 `.gitignore` 排除。
克隆仓库的人不会拿到 PDF，需要核对时请按下表自行下载。

## 处置记录（2026-09-20）

排查工作区时发现：这两个 PDF 曾被提交进公开仓库。直接原因是**当时没有任何针对本目录的
忽略规则**，而提交前没有检查 `git status` 里有没有不该进仓库的东西。

同一轮还发现一个**同源问题**：占位跑批产物的忽略规则写的是 `*.local.json`（点号），
而实际文件叫 `2026-09-19-local.json`（**连字符**）—— 规则与文件名对不上、永不生效，
于是"永不该入库"的占位结果也被提交了。两条规则均已修正，并各留了正反验证用例。

已做的处置：`git rm --cached` 停止跟踪（磁盘文件保留在本地）+ 补上忽略规则。

### 团队决定：不重写历史（2026-09-20）

这两个文件**仍存在于此前提交 `a296e80` 的历史中**，clone 该仓库仍可从历史取回。
团队决定**不**重写历史 —— 重写已公开的历史（`git filter-repo` + 强推）会改变提交哈希、
影响任何已 clone / fork 的副本，代价大于收益；且二者均为 arXiv 上可公开获取的预印本。

若后续（例如出版方提出异议）认定必须彻底移除，正确做法是：

```bash
# 需先安装 git-filter-repo；这是不可逆操作，且需要通知协作者
git filter-repo --path 参考文献/原文存档 --invert-paths
git push --force origin main
```

**注意**：本目录的 PDF 本身仍然保留在本地磁盘上（只是不受版本控制），
所以核对引用不受影响。
