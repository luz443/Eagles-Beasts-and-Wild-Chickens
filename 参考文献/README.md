# 参考文献（唯一引用登记处）

> **规则（2026-09-19 起）：任何要出现在方案、PPT 或演示视频里的来源，必须先在这里登记，再使用。**

| 要做的事 | 怎么做 |
| --- | --- |
| 新增一条引用 | 编号接续（当前到 R22，下一条 R23），追加到 `研究复盘助手-参考文献.docx` 第一节；同时同步仓库副本 `实现代码/docs/references.md`，两边编号必须一致 |
| 只有线索、没核实到原始页面 | 写进第四节并标注「不得引用」，不得出现在 PPT、视频或方案里 |
| 转引 | 条目里写明「经…转引」，不得写成直接引用 |
| 原文副本 | 放 `原文存档/`；**该目录不得打包进开源仓库**（出版方文件再分发有版权问题） |
| 链接失效 | 从作品引用中撤下，并在清单里把状态标为「已失效」 |

## 条目字段口径（五列，缺一不可）

编号 / 完整条目（作者·标题·出处）/ 链接 / 支撑我们的哪一处判断 / 关键原文或数字

## 本目录内容

| 文件 | 说明 |
| --- | --- |
| `研究复盘助手-参考文献.docx` | 正式清单：已核实引用、检索与核实方法、引用规范、未核实项、原文存档说明 |
| `原文存档/` | 可公开获取的原文副本，仅供核对，不进仓库 |
| `README.md` | 本文件 |

## 为什么要这样管

评委或后继者要能逐条复核「这句话是从哪来的」。把**已核实**与**未核实**分开、把**引用**与**原文副本**分开，
是避免被质疑学术不端最直接的做法，也避免把出版方文件打进公开仓库。
