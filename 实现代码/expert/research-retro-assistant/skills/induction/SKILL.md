# 技能 4：归纳假设（induction）

## 用途

同一个阻塞点积累了多条记录之后，把它们归纳成**一条可立项、可验证的假设**——
这是"失败经验"变成"下一个实验"的地方。

## 什么时候用

- 用户问「这些失败说明了什么」「能不能立项」「值不值得做」；
- 同一阻塞点的记录数达到门槛（≥3 条）。

## 输入

库文件（或记录列表）。

## 步骤

1. **取候选分组**（确定性：门槛由代码判，别自己数）：

```bash
python3 bin/rra_cli.py induction-candidates <库文件>
```

   返回 `groups`：同一阻塞点 ≥3 条的分组，以及组内档案编号。

2. **读组内每条记录**，找出共同点与**反例**：
   - 共同点必须能落到条件维度上；
   - 组内有反例（同类条件但结论不同）必须写在输出里，不许隐去。
3. **写假设**（这部分只有你能做）：一条可验证的陈述 + 验证方法 + 判据（什么结果算证实/证伪）。
4. **标注证据强度**：给出「几条支持 / 几条反例 / 是否只有模拟数据」。
   证据不足时明确写「暂不立项」，不要为了产出而立项。
5. **可迁移性**：说明这个假设在什么条件下适用、什么条件下不适用。

## 输出

- 假设清单（每条含：陈述 / 依据档案编号 / 反例 / 验证方法 / 判据 / 证据强度 / 适用边界）。
- 中文说明：为什么现在是立项的时机，或为什么还不是。

## 拒绝条件（必须照做）

- 分组不足门槛（<3 条）→ 不立假设，改建议「再积累 N 条」。
- 只有模拟数据支撑 → 必须在输出里标注，不得当作真实结论。
- 组内存在反例却写「一致支持」→ 属于造假，禁止。
- 不许把归纳结果写成成品档案塞进库里——假设是给下一个实验用的，不是已完成的事实。
