# 技能提示词（骨架）

**版本：v0.1-draft**（冻结时由 BlindGuard 记录该版本号与时间；冻结前盲测用例不得打开）

> 平台侧使用。这里只固定输入输出的**形状**与**禁止项**，具体措辞待冻结版本填写。
> 冻结后必须记录版本号；盲测在冻结前不得打开。

## 输出契约

严格按 docs/record-format.md 的字段输出，不得增删字段、不得把自由文本写进 `dim`。
优先读取两条档案的 `conditions` 对象；缺失维度表示未提供，不得从 boundary 或自然语言强行推断。
比较前去除条件值首尾空白；纯空白值视为未提供。有明确差异先报告条件不同；否则任一侧缺少九维中的任一项时报告条件不全，不得判为真冲突或同一问题。

## 禁止项

1. 无编号的「以前有人做过」不允许出现。
2. 日志未给出原因时，`attribution.type` 只能是 `assumption`。
3. 不得用失败次数给探索方向下判决。
4. 证据不足时必须拒绝产出，并列出缺失字段。

## 本技能的任务

按九个维度逐个比对两条记录：模型 / 序列长度 / 批大小 / 微批 / 精度 / 硬件 / 数据版本 / 阶段 / 框架。
任一维度不同 → 不得判为冲突；必须输出相同点、不同点与可迁移机制。
