## 访问条件

当前使用 Cloudflare Quick Tunnel，已经实际打开并验证。它是临时公网演示链接，不是永久托管：电脑关机、休眠、网络断开或 cloudflared/HTTP 进程停止都会影响访问。重建隧道会得到不同地址。未配置付费托管、域名或账户；现有 GitHub 凭据返回 401，因此没有伪称永久部署。

后台 HTTP 服务只提供 web/ 静态目录，监听 127.0.0.1:8124。cloudflared 转发此端口。当前进程：HTTP 35500，隧道 30516。工具与日志位于 C:/Users/Lenovo/Documents/Codex/2026-09-19/d-ai-docs-review-prompt-backend/work/publish/。

永久部署时，将 web/ 全部内容部署到任意静态 HTTPS 托管即可；路由使用 hash，不需要服务端重写。不要把项目根目录作为站点根目录。

- 矩阵支持查找、阻塞点筛选、2–4 条选择、差异与缺失分开显示，保留专家 same/diff 和迁移说明。

- 证据侧边抽屉支持关闭、Escape、焦点恢复和打开来源档案。
- 失败地图分离独立成功经验，折叠低样本区，按尝试数量排序并展开研究轨迹。
- 孵化计划支持状态、动作、负责人、日期、结果、本地保存与独立备份恢复。

- 立项查询、地图选中项、矩阵选择、孵化阻塞点写入深链；跨页导航管理滚动和焦点。

## 功能边界

网页没有模型调用，条件缺失不自动猜测，专家侧与网页仍通过库文件手动交换。验证状态为使用者填写，不能当作系统独立证明。新网址与本机网址各自保存本地数据，可用导出/备份迁移。默认公开样例为 14 条模拟档案，测试纠错仅保存在本机测试浏览器，未写入公开样例。
